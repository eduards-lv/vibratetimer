# Vibrate Timer

Нативное приложение для Android на Kotlin. Создавайте несколько независимых таймеров: каждый срабатывает через заданное количество минут и подаёт выбранное число вибраций. Таймеры можно отменять по одному.

## Требования

- Android Studio (стабильная версия)
- JDK 17
- Android SDK 35 (устанавливается через SDK Manager)
- Gradle 8.9

Откройте проект в Android Studio и дождитесь синхронизации Gradle. Для сборки из консоли с установленным Gradle 8.9 выполните `gradle assembleDebug`. Gradle wrapper jar и APK в исходниках не включены.

## Работа таймера

Срабатывание планируется через системный AlarmManager, который может пробуждать устройство в режиме Doze. На Android 12 и новее для высокой точности требуется разрешить приложению точные будильники в системных настройках. После перезагрузки сохранённые таймеры восстанавливаются. Вибрация выполняется локально; уведомления показывают, какой таймер сработал. На Android 13+ уведомления требуют отдельного разрешения, вибрация от него не зависит.

Таймеры задаются в минутах (минимум 1), число импульсов — от 1 до 30.
